## Overview

**siTermi** is a portfolio Command Line Interface (CLI) project developed in Python. It is designed to bring an engaging, interactive AI experience directly to the terminal with a unique visual touch through dynamic *ASCII Art* mascot animations.

This project explores modern generative AI SDK integration, secure environment variable management, and interactive terminal state handling.

---

## Key Features

- **AI-Powered Responses:** Seamlessly integrated with Google Gemini models via the `google-genai` SDK.
- **Dynamic ASCII Mascot:** Features multiple visual expressions (Idle, Thinking, and Happy) to provide real-time visual feedback to the user.
- **Secure Configuration:** Implements environment variable management using `python-dotenv` to safeguard API keys.
- **Interactive CLI Loop:** A clean, loop-based command-line interface equipped with error handling and a safe exit option (`exit`).

---

## Tech Stack

- **Language:** Python 3.x
- **AI SDK:** Google GenAI (`google-genai`)
- **Environment Management:** Python-Dotenv (`python-dotenv`)
- **Environment Control:** Virtual Environment (`venv`)
